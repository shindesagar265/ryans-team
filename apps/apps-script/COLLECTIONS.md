# Google Sheets collection mapping

| Application collection | Sheet tab | Key |
|---|---|---|
| classes | Classes | id |
| students | Students | id |
| enrollments | Enrollments | id |
| attendance | Attendance | id |
| message templates | MessageTemplates | id |
| users | Users | id |

Headers are initialized on first access. No sample rows or seed data are created. Apps Script executions are serialized with a script lock for enrollment capacity updates.
